
# Test Scenarios – Shopping Flow

---

## Scenario ID: TS-05
**Title:** Verify user can add a product to the shopping cart

**Scenario Description:**
The system should allow a logged-in user to add a product to the shopping cart from the product page.

---

## Scenario ID: TS-06
**Title:** Verify gift card purchase functionality

**Scenario Description:**
The system should allow users to purchase a gift card successfully through the checkout process.

---

## Scenario ID: TS-07
**Title:** Verify user can remove an item from the shopping cart

**Scenario Description:**
The system should allow users to remove products that were previously added to the shopping cart.

---

## Scenario ID: TS-08
**Title:** Verify cart item quantity update functionality

**Scenario Description:**
The system should allow users to update the quantity of items in the shopping cart.

---

## Scenario ID: TS-09
**Title:** Verify successful checkout process

**Scenario Description:**
The system should allow users to complete the checkout process and place an order successfully.
