
# Test Scenarios – Promo Code Management

---

## Scenario ID: TS-01
**Title:** Verify promo code creation functionality

**Scenario Description:**  
Admin user should be able to create a new promo code from the promo code management section.

**Related Feature:** Promo Code Management

---

## Scenario ID: TS-02
**Title:** Verify system prevents duplicate promo codes

**Scenario Description:**  
The system should prevent creation of promo codes that already exist in the system.

**Related Feature:** Promo Code Management

---

## Scenario ID: TS-03
**Title:** Verify validation of coupon parameters

**Scenario Description:**  
The system should validate coupon parameters and prevent creation of coupons with invalid values.

**Related Feature:** Promo Code Management

---

## Scenario ID: TS-04
**Title:** Verify coupon date validation

**Scenario Description:**  
The system should validate coupon start and end dates and prevent invalid date ranges.

**Related Feature:** Promo Code Management
