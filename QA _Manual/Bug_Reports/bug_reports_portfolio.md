## ID: BR-204

**Title:** Product names overlap in the Self‑Care category

**Status:** Done  
**Type:** Bug  
**Priority:** Low  

**Environment**
- Development
- Beta

**Browser:** Google Chrome  
**Device:** Mobile Device  
**Operating System:** Android  
**Reproducibility Rate:** 100%

### Description
In the Self‑Care category, product names overlap with each other in the product list, making the text difficult to read.

### Steps to Reproduce
1. Open the Sample E‑commerce Website
2. Navigate to the **Self‑Care** category
3. View the list of products

### Actual Result
Product names overlap each other.

### Expected Result
Each product name should be displayed clearly without overlapping.

## ID: BR-38

**Title:** Selected language resets to default after returning to homepage

**Status:** Done  
**Type:** Bug  
**Priority:** Medium  

**Environment**
- Development
- Beta

**Browser:** Web Browser  
**Device:** Personal Computer  
**Operating System:** Windows

**Reproducibility Rate:** 100%

### Description
When a user changes the website language, the selected language applies correctly on the current page. However, after returning to the homepage, the website resets to the default language.

### Steps to Reproduce
1. Open the website (default language)
2. Change the language to another language (e.g., English)
3. Navigate through several pages
4. Return to the homepage

### Actual Result
The site language resets to the default language.

### Expected Result
The website should remember and maintain the selected language across pages.

## ID: BR-203

**Title:** Items added to cart are not visible in another browser

**Status:** Done  
**Type:** Bug  
**Priority:** Medium  

**Environment**
- Development
- Beta

**Browser:** Google Chrome / Microsoft Edge  
**Device:** Personal Computer  
**Operating System:** Windows

**Reproducibility Rate:** 100%

### Description
Products added to the cart in one browser are not visible when accessing the same account from another browser.

### Steps to Reproduce
1. Open the website in Google Chrome
2. Add products to the cart
3. Open the same account in another browser
4. Check the cart

### Actual Result
The cart appears empty in the second browser.

### Expected Result
The cart should display the same items across browsers when the user is logged in.
